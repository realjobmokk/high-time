# 🎓 HighTime (하이타임) - 고등학생용 에브리타임 프로토타입

대한민국 고등학생들을 위한 **전국 전공/진로 정보 공유 커뮤니티 및 학교생활 플랫폼**입니다.

---

## 📌 핵심 기능

1. **전국 전공·계열별 정보 공유 라운지 (`MajorBoard`)**
   - 컴퓨터·IT, 의약학, 자연과학, 경영경제, 사회법학, 인문어문, 교육, 예체능 등 고교 진로 맞춤형 분류
   - 세특(세부능력 및 특기사항), 탐구보고서, 추천도서, 동아리 연계 정보 전국 고교생 간 공유
   - 타 학교 학생 출신지(예: 하나고, 상산고, 대원외고 등) 및 학년(고1~고3) 표시
   - 게시글 작성, 좋아요, 댓글, 스크랩, **게시물 삭제 기능** 제공

2. **1:1 질문 & 맞춤 입시 상담소 (`CounselingAndQA`)**
   - 탐구 글 작성자 또는 우수 멘토에게 1:1 질문 신청 및 답변 열람
   - 학종(학생부종합), 교과, 정시, 논술 등 목표 대학/학과별 입시 컨설팅 Q&A

3. **우리 학교 전용 커뮤니티 (`SchoolBoard`)**
   - 소속 고등학교 재학생 전용 자유게시판, 정보/세특, 동아리, 분실물 찾기
   - 교내 익명 소통 및 게시글 작성/삭제 지원

4. **내 학교 생활 관리 (`SchoolLife`)**
   - 오늘의 급식 메뉴, 영양 칼로리, 알레르기 유발 정보 및 실시간 이모지 맛 평가
   - 월~금 교시별 주간 수업 시간표 및 현재 교시 하이라이트
   - 수능(D-Day), 기말고사, 전국연합학력평가 카운트다운

5. **1:1 채팅 & 기획 솔루션 (`DirectChat`)**
   - 1:1 질문이 수락된 학생 간 안전한 실시간 대화방 시뮬레이션
   - 고등학생 대상 1:1 채팅 도입 시 우려되는 부작용 분석 및 안전 설계 가이드 탑재

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: React 19, Vite 6
- **Styling**: Tailwind CSS v4, Pretendard 웹 폰트
- **Icons**: Lucide React
- **Persistence**: LocalStorage (새로고침 시에도 작성/삭제/수정 내역 영구 보존)

---

## 🚀 프로젝트 실행 방법

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 빌드
npm run build
```

브라우저에서 `http://localhost:5173/`으로 접속하여 모바일 프레임 모드로 시연할 수 있습니다.
